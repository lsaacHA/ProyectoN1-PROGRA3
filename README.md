Proyecto #1 de programacion 3 utilizado para que los funcionarios puedan apartar de una manera digital equipos o un espacio en concreto que necesiten para poder completar reuniones o otras tareas que tengan en su horario, esta "app" funciona para la facilidad de ver los horarios apartados de los equipos o salas y por quien fue apartado tambien para que los funcionarios aparten los equipos y se vea una grafica que demuestre la cantidad de equipos utilizados al rededor de un margen de tiempo.
